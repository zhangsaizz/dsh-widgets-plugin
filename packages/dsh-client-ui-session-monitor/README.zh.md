# @dsh-plugins/client-ui-session-monitor

[English](README.md) | 中文

浮动的「会话监控看板」挂件（web 端插件）。在 `shell.overlay` 里注册一个可拖动、
可折叠、可缩放的浮动面板，列出正在执行的会话及其状态（运行中 / 空闲 / 本轮完成），
会话完成一轮时主动弹提醒，点击任意会话即可一键跳转。带一个轻量 **Host 半**：
监听会话事件流里的 `turn/end` 结束原因并通过同源路由供浏览器轮询，让通知能区分
「正常完成」与「**出错 / 中止 / 阻塞 / 超出 token 上限**」；没有 Host 半时挂件
仍可用（退回基础通知状态）。

## 特性

- **实时会话列表**：投影标准 `useSessions` 会话列表 store（**无 Host RPC、无
  轮询**——运行时响应式推送会话摘要与 `running` 状态变化）。运行中的会话置顶并
  带呼吸绿点；每行显示会话标题、工作区派生名、当前徽标、等待输入状态与相对更新
  时间。**可配置的时间范围**（默认最近 1 小时）只保留窗口内活跃过的会话——运行中
  的会话始终显示，被隐藏的旧会话数量会有淡色提示。**子代理会话默认过滤**（可在
  配置弹窗里重新开启显示与提醒），但主代理行会显示紧凑的 **子×N** 徽标，表示
  当前共有 N 个子代理（含嵌套派生的所有后代）正在执行。每行还会显示 **后×N** 徽标——该会话当前在后台
   执行的任务数（`session/jobs` 镜像，只统计运行中/停止中的任务，已结束的不计）。
  当主会话自身不在回合中、但仍有子代理或后台任务在执行时，状态不再显示「空闲」，
  而是显示 **子代理执行中**（紫）/ **后台执行中**（青），并像运行中一样置顶、
  不被时间窗隐藏；「只显示忙碌中」开关保留运行中 + 有子代理/后台任务在执行的会话，只隐藏真正空闲的。若该行还带「本轮
  完成」标记，状态文案优先显示忙碌标签（状态点仍保持本轮完成的橙色）；头部与
  收起胶囊的计数也统计这类忙碌会话（显示「N 个忙碌中」）。
- **完成一轮主动提醒**：监控 `running` 由 true→false 的边沿（一次边沿 = 完成
  一轮，goal 模式的多轮同样适用），弹出提醒条，带**跳转** 与 **知道了** 两个动作；
  提醒条会标注轮次（如「已完成第 3 轮」——挂载 Host 半后为累计准确轮次，否则为挂件打开期间观测到的轮次）。
  **提醒条按状态配色区分**：琥珀色 ✓ 正常完成一轮；蓝色 ❓「需要你处理」——
  会话停下等待你的回答（`question`）；橙色 ⏳「待审核」——等待你的审批
  （`approval`）；紫色 📋「计划待评审」——等待计划评审（`plan-review`）；
  紫色 ⇄ 子代理完成（开启显示子代理时）；挂载 Host 半后还可区分：**红色 ✕ 出错、
  灰色 ■ 已中止、橙色 ⚠ 受阻、⇥ 超出 token 上限、⏸ 中断**。
  **会话中途停下等你时也立即提醒**：工具请求审批、向你提问、进入计划评审这类暂停
  发生在回合中途（`running` 不变），挂件盯 `pendingInteraction` 出现边沿并立刻弹
  对应提醒（待审核 / 需要你处理 / 计划待评审），不用等回合结束。多个会话同时完成各自堆叠成独立提醒条（新的
  在最上，自动模式堆叠上限 5 条、超出丢最旧）。两种关闭方式：**自动消失**（N 秒后
  自动关闭）与 **需确认**（提醒一直停留直到你确认——同一会话的新一轮会替换旧提醒，
  未确认的提醒不会被新提醒挤掉，堆叠过高时可滚动）。可选提示音（与系统通知一致，仅在你离开页面时响）。开启**浏览器通知**
  后系统通知同步按状态使用相同标题；点击系统通知会直达会话并同时关闭页面内对应的
  提醒条（该轮已完成确认，页面提醒不再需要）。**系统通知只在你离开页面**（标签页
  隐藏、窗口最小化或失焦）**时发出**——你就在当前页上时，页面内提醒条已经足够，
  不再弹 OS 级通知。**回到页面自动清理**：系统通知把你叫回页面后——浏览器窗口
  重新聚焦或标签页重新可见时——当前会话的那条系统通知自动关闭，「本轮完成」徽标
  一并清除（页面内提醒条保留：回到页面后它就是页内通知；其他会话的完成提醒不动，
  仍需你处理）。**页面完全关闭**期间的完成无法提醒——浏览器限制：网页不在运行就没有 JS，系统通知只覆盖「页面开着但切走」。**多标签联动**：同一会话在多个标签页打开时，任一标签页点
  「知道了/跳转」、打开会话或「清除完成标记」，其他标签页的同会话提醒条与完成
  标记会同步关闭（BroadcastChannel），设置改动也跨标签同步；会话被删除/归档后，
  其待发提醒与已弹提醒条自动清除。
- **点击跳转**：点击任意列表行——或提醒条上的「跳转」按钮——立即把应用切到该
  会话（`ctx.sessions.open`）。
- **完成标记**：挂件打开期间完成一轮的会话在列表里带「本轮完成」徽标，直到被
  访问（打开该会话，或点底部「清除完成标记」）。
- **可配置**：小组件管理页的「配置」弹窗可开关提醒、选择关闭方式与秒数、提示音、
  **浏览器通知**（勾选时浏览器请求授权，开启后完成一轮同时发系统通知——**仅当你离开页面时发出**；点击通知
  直达会话并同时关闭页面内对应提醒条，同会话通知自动替换不堆叠）、是否提醒当前会话（默认关——你正在看它，
  无需再弹提醒；但停下等你输入/确认时仍会提醒；如果你切到其他标签页/窗口、页面不可见或失焦，当前会话完成仍会提醒，页面内提醒条会留着等你
  回来，开启浏览器通知则系统通知直达）、是否显示子代理（默认
  关）、只显示忙碌中、**时间范围**（全部 / 15 分钟～24 小时）、是否显示完成标记；
  所有设置与面板位置都持久化到 `localStorage`。开启「只显示忙碌中」时时间范围
  暂不生效——配置面板会淡化该选项并提示"关掉后立即生效"，值仍可预先配置。

## 结构

```
src/index.ts                  # Host 半：turn/end 结束原因跟踪 + 状态路由
src/client/index.ts           # 浏览器 apply + inject
src/client/SessionMonitorWidget.tsx
src/client/SessionMonitorWidget.module.css
src/client/SessionSettings.tsx
src/client/SessionSettings.module.css
src/client/settings.ts        # 共享设置 / 位置持久化 + 提示音
src/client/locales.ts         # 字典 NS `session-monitor`（zh / en）
lib/index.js                  # Host 构建产物（ESM）
lib/client.js                 # 浏览器构建产物（ModuleLoader CJS bundle）
```

## 构建

根目录 `scripts/build.mjs` 用 esbuild 构建；本包在其中的
「Session-monitor client bundle」段产出 `lib/client.js`，Host 半入口
（`src/index.ts`）构建为 `lib/index.js`：

```bash
pnpm install
pnpm build   # 等价于 node scripts/build.mjs
```

## 挂载

一个插件行同时挂载两半：**Host 半**（经包根入口加载，监听会话事件流并在 web
profile 上提供 `/_dsh/session-monitor/status` 路由）与**浏览器半**（经
`exports["./client"]` 加载，在 `shell.overlay` 渲染看板并每几秒轮询该路由）。
区分「出错/中止/阻塞/token 上限」等通知状态需要 Host 半；没有它浏览器退回基础
状态（完成 / 需要处理 / 子代理）。**Host 半需要重启 web 服务才能被加载**。

推荐直接安装 `@dsh-plugins/dsh-widgets-plugin`（发布后
`dsh plugin --profile <name> add @dsh-plugins/dsh-widgets-plugin`），一次挂载本看板与
全部小组件；本地开发可直接 `link:` 本仓库 bundle（见根 README「安装」）。

## 使用

挂载后无需配置即可使用：

1. **查看**——面板列出存活会话（子代理默认过滤），运行中的置顶并带呼吸点，
   头部与收起胶囊显示忙碌数量（运行中 + 有子代理/后台任务在执行的会话）；每行
   带 **后×N** 徽标显示该会话后台执行任务数。
2. **跳转**——点击任意列表行，应用立即切到该会话。
3. **收起 / 缩放**——点头部「—」按钮把面板收成胶囊（点胶囊再次展开）；拖面板
   右下角的缩放手柄可在 0.6×～1.6× 之间缩放。位置与缩放都持久化。
4. **提醒**——会话完成一轮时弹出提醒条（按设置自动消失或需确认）；点「跳转」
   直达该会话，「知道了」关闭提醒。
5. **配置**——Web 设置 → 小组件管理 → 会话监控看板 → **配置**，调节提醒（开关、
   关闭方式、秒数、音效、当前会话范围）、是否显示子代理（默认关）与列表
   （只显示忙碌中、完成标记）。
